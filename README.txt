Stagecoach Morecambe Running Sheets - starter app

Files:
- index.html: mobile-friendly running-sheet PDF search app
- manifest.json: installable web app metadata

Use:
1. Host these files on an HTTPS website (for example, a private static web host).
2. Open the hosted address in Chrome on your Android phone.
3. Import the running-sheet PDFs from your phone.
4. Select the day, enter a duty number, and tap Search duties.

The app stores imported PDF text locally in the browser on that device. PDFs are not uploaded to a server.
Note: Monday, Tuesday, and Friday lookups also consider a PDF whose filename contains Wednesday, per your running-sheet arrangement. Name each PDF with its day (e.g. Thursday.pdf) for reliable filtering.
This is a starter web app, not an officially supported Stagecoach product.
